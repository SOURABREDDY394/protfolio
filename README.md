## 🏛️ Overview

This repository powers the personal portfolio of **Sourab Reddy**, an **AI Engineer & Full-Stack Developer** based in Hyderabad, India.

Built with native web standards and a bold neo-brutalist poster aesthetic, the site fuses fluid typography, dynamic theme colorways, tactile micro-animations, and interactive architecture drawers to showcase production-grade software engineering.

### 🌟 Key Design & Architectural Highlights

- **⚡ High-Energy Poster Brutalist Typography**: Fluid typography powered by Google's [Anybody](https://fonts.google.com/specimen/Anybody) and [Instrument Sans](https://fonts.google.com/specimen/Instrument+Sans) with variable font width scaling.
- **🎨 4 Curated Dynamic Theme Colorways**:
  - `Tangerine / Cobalt`: Electric orange, deep contrast cobalt blue, bubblegum accents.
  - `Cyber`: Dark slate, cyan neon, emerald badges.
  - `Grape`: Violet base with amber and candy highlights.
  - `Emerald`: Deep forest green canvas with sunset coral.
- **🧱 Interactive Hero Poster Wall**: 11 tactile letter blocks forming `SOURAB REDDY` with physics-like hover rotations, interactive stamp stickers, and animated live availability pill.
- **📂 Architecture Detail Drawers**: Every case study features an expandable architecture panel inspecting role responsibilities, tech stack, latency benchmarks, and verified direct links.
- **📱 Fully Responsive & Zero Heavy Bundlers**: Pure HTML5, CSS3, and modern JavaScript with zero heavy build steps, zero bloated client runtime, and ultra-fast First Contentful Paint (<0.3s).

## 🛠️ Tech Stack & Architecture

- **Markup**: HTML5 (Accessible landmarks, OpenGraph meta tags, SEO-optimized semantic structure)
- **Styling**: Vanilla CSS3 (CSS Custom Properties, fluid `clamp()` sizing, CSS Grid, aspect-ratio containers)
- **Interactions**: Vanilla JavaScript (ES6+, Theme Switcher with `localStorage`, Accordion state management)
- **Typography**: [Anybody](https://fonts.google.com/specimen/Anybody) & [Instrument Sans](https://fonts.google.com/specimen/Instrument+Sans)
- **Hosting & Deployment**: [Vercel](https://vercel.com/) Edge Network

## 💻 Local Development

Because this project uses vanilla web standards with no heavy build step, run it directly in any local environment:

### Option 1: Python HTTP Server
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000`.

### Option 2: Node / npx serve
```bash
npx -y serve .
```
